# Python 기반 백테스트 및 규칙 기반 모의매매

과거 데이터로 신규 매매 전략을 검증하는 백테스트와, Alpaca 모의계좌에서 규칙 기반 매매를 실행하는 시스템을 구현한 개인 프로젝트입니다.

백테스트 전략과 현재 모의매매 전략은 서로 다릅니다. 백테스트에서 선정한 파라미터를 모의매매에 그대로 적용한 구조가 아니며, LLM이 주문 여부를 결정하지 않습니다.

---

**구성 및 구현 상태**

| 구성 | 주요 내용 | 상태 |
| --- | --- | --- |
| 신규 전략 백테스트 | EMA·Stochastic RSI 기반 전략, 그리드서치, 성과 분석 | 구현 및 여러 기간 검증 진행 중 |
| 규칙 기반 모의매매 | 이동평균선·RSI 기반 매수, 트레일링 스탑·볼린저밴드 기준 매도 | 구현 및 모의계좌 실행 경험 |
| 클라우드 실행 | Oracle Cloud VM에서 Python 프로세스 실행 | 실행 환경 구축 |
| LLM 연계 | 별도 분석 리포트 시스템과의 도구 연계 | 향후 계획 |

---

# 1. 신규 전략 백테스트

**처리 흐름**

과거 일봉·5분봉 수집 및 저장 → 지표 계산 → 날짜·시간별 매매 시뮬레이션 → 파라미터 조합 비교 → 성과 분석

---

**주요 기능**
- SPY와 개별 종목의 종가·EMA 9·EMA 21 조건으로 거래 대상 선정
- Stochastic RSI 교차·기준값을 이용한 진입 및 청산 판단
- 손절 조건 적용
- 매수·매도 기준값과 손절 비율의 그리드서치
- 수익률·일별 자산 기준 MDD·승률 산출
- 매도 사유별 건수·총손익·평균손익 집계
- 자산 추이 시각화
- S&P 500의 추세별로 구분한 여러 기간에서 검증 진행

---

**문제 해결: 일봉 미래참조 오류**

거래 시작 시점의 필터가 아직 확정되지 않은 당일 종가를 참조하는 오류를 발견했습니다.

현재 거래일 이전의 일봉만 추출하고, 가장 최근에 확정된 종가와 EMA를 사용하도록 수정했습니다. 동일한 제한을 SPY와 개별 종목 필터에 적용했습니다. 이 수정은 일봉 필터의 당일 데이터 참조를 제한한 것으로, 백테스트 전체의 미래참조 가능성을 모두 검증했다는 의미는 아닙니다.

---

**매도 조건 개선 실험**

트레일링 스탑 적용 전후의 최고 수익률 조합을 비교하고, 전체 성과와 매도 사유별 손익을 함께 분석했습니다.

- 동일 기간과 기존 매수·매도 파라미터 탐색 범위에서 비교
- 일부 성과 지표가 개선되었지만 트레일링 스탑 매도에서 손실 발생
- 결과에는 트레일링 스탑 추가와 선정된 파라미터 차이가 함께 반영될 수 있음
- 청산 사유별 평균 손익 변화만으로 동일 거래의 개선을 단정하지 않음

---

**검증 가정 및 한계**

| 항목 | 현재 가정·한계 |
| --- | --- |
| 구성 종목 | 현재 시점의 S&P 500 구성 종목으로 과거 기간 검증 |
| 생존편향 | 테스트 당시 구성 종목과 다르므로 편향 가능성 존재 |
| 거래 비용 | 수수료·슬리피지 미반영 |
| 파라미터 선정 | 테스트 기간 내 최고 수익률 조합 선정 |
| 결과 해석 | 과거 성과가 다른 기간이나 실거래 성과를 보장하지 않음 |

# 2. 규칙 기반 모의매매

**처리 흐름**

시장·종목 필터링 → 매수·매도 신호 검사 → 모의 주문 → 장 마감 청산 요청 및 잔여 상태 확인

---

**주요 기능**
- SPY·개별 종목의 종가와 단순이동평균 조건으로 거래 대상 선정
- 단기 이동평균선·RSI 조건으로 매수 판단
- 보유 중 관측한 최고가 기반 트레일링 스탑 적용
- 볼린저밴드 기준 손절 조건 적용
- 최대 보유 종목 수·종목당 주문 규모 제한
- 장 마감 미체결 주문 취소 및 포지션 청산 요청
- 뉴욕 현지 시간 기준으로 실행 구간 관리

---

**향후 개선 계획**
- 테스트 당시의 S&P 500 구성 종목을 반영한 검증
- 수수료·슬리피지를 적용한 성과 비교
- 매수·매도 기록을 연결한 개별 거래 분석
- 시장 추세별 성과와 파라미터 일관성 검토
- 미체결 주문까지 고려한 중복 주문 방지
- 재시작 시 보유 종목별 최고가 등 상태 복원
- 휴장일·조기 폐장일 및 실행 시각 누락 대응
- 분석·조회·검증 도구 연계와 별도의 주문 위험 관리 절차 설계

---

**주의사항**

학습·연구 및 모의거래 목적의 프로젝트입니다. 백테스트와 모의거래 결과는 실거래 성과를 보장하지 않습니다.
