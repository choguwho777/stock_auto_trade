    - 최신 지표를 적용한 새로운 로직으로 백테스팅 및 그리드서치 기반 파라미터 최적화 진행 중.

## 4. 시스템 아키텍처 및 프로세스

- **데이터 수집**
    - Alpaca / Toss / yfinance API: S&P 500 기술적 지표용 정형 주가 데이터 수집
    - Finnhub API: 기업 관련 최근 3일간 비정형 뉴스 데이터 수집
- **지표 계산 및 통합 분석**
    - Pandas / Pandas_ta: 이동평균선, 볼린저 밴드, RSI 등 핵심 지표 산출
    - Matplotlib: 주가 추세 및 RSI 과매수/과매도 영역 2단 차트 시각화
    - Gemini 3.6 Flash: 차트 이미지, 재무 지표, 뉴스 통합 분석 리포트 생성
- **백테스팅 & 파라미터 최적화**
    - Grid Search: 다중 변수 조합 백테스트로 수익률, MDD, 승률 최적화 파라미터 도출
    - scikit-learn: 장기간 데이터 분석 시, 섹터 층화 추출로 50개 종목 샘플 구성하여 편향 방지
- **클라우드 인프라 구축 및 자동화**
    - Oracle Cloud VM: 백그라운드 상시 가동
    - 타임라인별 자동 실행 루틴: 프리마켓/정규장/장마감 각 타임라인에 맞는 자동 루틴 실행

## 5. 핵심 구현 내용

- **정형, 비정형 데이터 처리 파이프라인**
    - **정형 데이터 스캐닝:** S&P 500 종목을 대상으로 이동평균선, 볼린저 밴드, RSI 지표를 실시간 산출하고, 골든크로스 및 과매도 이탈 등 기술적 특이 신호 포착.
    - **비정형 데이터 통합 및 AI 분석:** 최신 뉴스 헤드라인과 차트 이미지, 재무 지표(PER, ROE 등)를 LLM 모델에 전달하여 종합 리포트 생성.
    - **이메일 리포팅 자동화:** 차트 이미지가 포함된 HTML 리포트를 작성하여 Gmail SMTP로 자동 발송.
- **데이터 기반 백테스팅 및 파라미터 최적화**
    - **그리드서치 최적화:** 진입/청산 기준, 고정 손절 비율, 트레일링 스탑 비율 등 파라미터 조합에 대해 그리드서치 백테스팅 진행, 파라미터 최적화.
    - **데이터 기반 알고리즘 재설계:** 수익률 외 MDD(최대 낙폭), 승률, 매도사유별 통계를 종합 평가하여 수익 저하 원인을 분석하고 로직 개선.
        - **문제 해결 사례:**
            - **문제:** stoch RSI 매수/매도만 적용 시, 수익 확정 타이밍에 대한 조건 부재로 건당 평균 수익이 매우 낮음**(+$1.90)**.
            - **가설 및 해결:** 트레일링 스탑을 적용하여 고점 대비 일정 비율 하락 시 익절 매도하도록 설정.
            - **결과:** stoch RSI 매도 건당 수익 개선**(+$1.90 → +$11.44),**
            수익률 향상**(0.91% → 1.08%)** 및 MDD 개선**(-1.33% → -1.11%)** 확인.
            - **차기 과제:** 트레일링 스탑 활성화 시 발생한 건당 손실**(-$96.85)** 보완을 위해 활성화 조건 도입 고려.
- **클라우드 인프라 구축 및 자동화**
    - **Oracle Cloud VM 활용:** 클라우드 인스턴스 세팅 및 개발 환경 구성.
    - **클라우드 상시 가동:** Oracle Cloud Infrastructure 환경을 구축하여, 미 동부 시간(EST) 기준 24시간 백그라운드에서 실행되는 자동매매 시스템 구축.
    - **타임라인별 프로세스 자동화:**
        - **프리마켓:** SPY 지수 및 S&P 500 개별 종목 1, 2차 추세 필터링.
        - **정규장:** 5분 단위 스캐닝 실시 후 조건 충족 종목 자동 매매 주문.
        - **장마감:** 미체결 주문 취소 및 잔여 포지션 일괄 매도.

## 7. 인사이트 및 연계

- **실험 변수 제어 및 최적화 프로세스 체득, 반도체 공정과의 시너지:**
단순히 코드를 구현하는 것에 그치지 않고, stoch RSI와 트레일링 스탑 적용 시의 매도 건당 손익, MDD, 승률 변화 등을 수치로 정량 분석했음. 데이터 분석 파이프라인 구축 경험과 데이터 분석을 통해 특정 제어 변수의 문제점을 식별하고 파라미터를 다각도로 재설계해 본 경험은 향후 반도체 공정 변수 최적화 및 수율 제어 메커니즘과 직결됨.
- **규칙 기반 제약 극복 및 ‘AI Agent 전업 투자’로의 통합 목표:**
현재 시스템은 상승장 필터링 등 수익률을 보존하기 위한 엄격한 규칙 제약이 다수 적용되어있음. 이로 인해 시장 변화에 유연하게 대처하기 어렵다는 한계를 식별함. 이를 극복하기 위해 **① 정형/비정형 데이터 수집 및 분석 리포트 파이프라인**과 **② 실시간 매매 자동화 파이프라인**을 하나로 통합하는 ‘AI Agent 전업투자 시스템’으로의 고도화를 목표로 설정. AI Agent가 자율적으로 분석 가치가 있는 종목을 발굴 및 분석하고 시장 상황 변화에 맞춰 유연하게 전략을 설정하여 실시간 매매를 수행하는 구조를 구상함.
