# Python 기반 전략 백테스트 및 규칙 기반 모의매매

과거 데이터로 신규 매매 전략을 검증하는 백테스트와, Alpaca 모의계좌에서 규칙 기반 매매를 실행하는 시스템을 구현한 개인 프로젝트입니다.

백테스트 전략과 현재 모의매매 전략은 서로 다릅니다. 백테스트에서 선정한 파라미터를 모의매매에 그대로 적용한 구조가 아니며, LLM이 주문 여부를 결정하지 않습니다.

---

## 구성 및 구현 상태

| 구성 | 주요 내용 | 상태 |
| --- | --- | --- |
| 신규 전략 백테스트 | EMA·Stochastic RSI 기반 전략, 그리드서치, 성과 분석 | 구현 및 여러 기간 검증 진행 중 |
| 규칙 기반 모의매매 | 이동평균선·RSI 기반 매수, 트레일링 스탑·볼린저밴드 기준 매도 | 구현 및 모의계좌 실행 경험 |
| 클라우드 실행 | Oracle Cloud VM에서 Python 프로세스 실행 | 실행 환경 구축 |
| LLM 연계 | 별도 분석 리포트 시스템과의 도구 연계 | 향후 계획 |
